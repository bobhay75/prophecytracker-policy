# Prophecy Tracker policy pages

Static policy/support website for the existing `www.prophecytracker.watch` GitHub Pages custom domain. The domain binding in `CNAME` is preserved.

`index.html` is the entry point. The privacy, terms and data deletion pages retain their existing substantive wording and contact address. This navigation/accessibility repair does not establish a new legal policy or verify a running Facebook integration.

Only HTML and CSS are required; no build, tracking script, application credentials, account registration or backend is present. Serve this directory with any static server. After deployment, check the index and all three policy links at the configured domain. DNS/TLS availability depends on the existing hosting configuration.
